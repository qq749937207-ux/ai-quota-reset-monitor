# 新模型预告：监测目录

这是「AI 新模型预告监测」的工程清单。日常按公司向用户展示；实际监测哪些公司，由用户在监测配置里勾选，不要默认全开。

账号身份已用公开 X 资料核实（用户 ID、认证与简介）。时间与说明按 Asia/Shanghai（UTC+8）记录。清单截至 2026-11-12。

收录范围只限该公司的新模型、新版本、公开预览和已定档的正式预告。排除招聘、营销、合作宣传、客服、额度重置，以及第三方模型上架。用户 ID 是稳定主键；检查前先核对 handle 仍指向原来的账号。

不能监测微博或微信公众号。国内厂商若主要在那些渠道先发，只看 X 和下面已确认的官网会有遗漏，向用户说明即可。
